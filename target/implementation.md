# 第一阶段开发记录

## 运行

沿用仓库要求的 Node 与 pnpm 版本，安装已有依赖后运行：

```powershell
pnpm dev:antd
```

管理端默认地址 `http://localhost:5666`，Nitro Mock 为 `http://localhost:5320/api`。模拟账号：`hq`（总部）、`store1`（上海一店）、`store2`（上海二店），密码均为 `123456`。Mock 仅供开发，重启服务会恢复示例数据，上传的模拟文件也会清空。

数据库实际位于 PostgreSQL 的 `jss_admin_dev`，运行方式见 `database/README.md`。页面当前使用 Mock，不直接写入此数据库。

## 已实现

基础管理模块：管理端登录、会话刷新/退出，总部与门店的数据范围，门店资料和环境媒体，员工任职与网页账号，角色权限和账号授权，会员建档/筛选/资料/持卡详情，卡种和通卡版本管理。沿用 Ant Design Vue 默认表单和列表，不增加 UI 库。

数据库已执行组织权限、会员卡种两批迁移及初始数据。未来端身份、潜客跟进和会员分配表随基础结构预留，未添加其他端 API。

课程模块：操课产品、排课与教练/场地冲突校验、代预约与容量/权益预占、取消预约释放次数、签到每15秒刷新及当天汇总、只读私教上课记录、体测录入与报告上传。二维码入口在尚未配置实际渠道时明确返回错误。

数据库第三批迁移已执行，包含课程、预约、签到、体测、二维码和未来训练计划/运动记录预留表，累计38张表。预约与门店隔离、权益释放和体测校验已验证。

合同与审批：合同PDF上传及模板版本、合同原件/签署信息/事件查看、未签提醒结果、顺序审批模板、仅当前指定总部审批人作出决定。模拟合同PDF明确标注开发示例；未接入渠道的提醒记录为失败，未向外发送。

第四批数据库迁移和开发示例已执行，累计47张表。累计16项业务检查通过，并在浏览器验证审批提交、提醒结果及PDF读取。

设备、营销等业务模块将继续按设计中的顺序添加；此记录不表示第一阶段全部完成。Go 后端尚未开始。
