# 第一阶段开发记录

## 运行

沿用仓库要求的 Node 与 pnpm 版本，安装已有依赖后运行：

```powershell
pnpm dev:antd
```

管理端默认地址 `http://localhost:5666`，Nitro Mock 为 `http://localhost:5320/api`。模拟账号：`hq`（总部）、`store1`（上海一店）、`store2`（上海二店），密码均为 `123456`。Mock 仅供开发，重启服务会恢复示例数据，上传的模拟文件也会清空。

数据库实际位于 PostgreSQL 的 `jss_admin_dev`，运行方式见 `database/README.md`。页面当前使用 Mock，不直接写入此数据库。

## 已实现

基础管理模块：管理端登录、会话刷新/退出，总部与门店的数据范围，门店资料和环境媒体，员工任职与网页账号，角色权限和账号授权，会员建档/筛选/资料/持卡详情，卡种和通卡版本管理。沿用 Ant Design Vue 默认表单和列表，不增加 UI 库。

数据库已执行组织权限、会员卡种两批迁移及初始数据。未来端身份、潜客跟进和会员分配表随基础结构预留，未添加其他端 API。

课程模块：操课产品、排课与教练/场地冲突校验、代预约与容量/权益预占、取消预约释放次数、签到每15秒刷新及当天汇总、只读私教上课记录、体测录入与报告上传。二维码入口在尚未配置实际渠道时明确返回错误。

数据库第三批迁移已执行，包含课程、预约、签到、体测、二维码和未来训练计划/运动记录预留表，累计38张表。预约与门店隔离、权益释放和体测校验已验证。

合同与审批：合同PDF上传及模板版本、合同原件/签署信息/事件查看、未签提醒结果、顺序审批模板、仅当前指定总部审批人作出决定。模拟合同PDF明确标注开发示例；未接入渠道的提醒记录为失败，未向外发送。

第四批数据库迁移和开发示例已执行，累计47张表。累计16项业务检查通过，并在浏览器验证审批提交、提醒结果及PDF读取。

设备与黑名单：设备资料、柜格配置、远程命令和操作历史、器械教学上传/查看/停用、全门店黑名单生效与撤销。指令按请求键防重复，柜格校验所属设备和占用；仅模拟厂商返回明确标注的模拟成功，未接入厂商则显示失败。

第五批数据库迁移及设备示例已执行，累计62张表；人脸、客户端设备、门禁事件和异常记录只预留数据库。累计20项业务检查通过，并验证浏览器模拟开门和教学上传。

售卡与报表：按店配置在线售卡、连续包月、自助核销；查看自主办卡订单和支付/退款明细、包月周期、核销记录；门店/员工业绩、会员汇总和会员卡报表。支付与退款按各自发生时间统计，金额在汇总中按整数分计算。会员增加私教与临期筛选，列表增加按月和日期范围。

第六批数据库迁移及销售示例已执行，累计77张表。累计23项业务检查通过，并在浏览器验证售卡设置保存、业绩汇总和订单详情。

营销：积分规则版本与兑换商品、积分流水/兑换记录，券模板、按张数分配门店额度、批量发券及逐人结果、额度流水、会员券，礼品码首次明文下载和后续掩码查询，私信/批量消息与投递状态。批次支持幂等键，分配按提交时店铺快照，发券校验额度并释放失败预占。

第七批数据库迁移及营销示例已执行，累计100张表。累计28项业务检查通过，浏览器验证每店分配100张、发券1张后剩余99张。真实消息渠道仍未接入。

内容运营：总部展示配置、活动与报名记录、加盟品牌及三种模型、加盟咨询跟进，门店评价和匿名反馈汇总。发布校验媒体、链接、活动容量，匿名反馈不返回身份字段。第八批数据库迁移已执行，累计113张表；累计31项业务检查通过，浏览器验证展示设置、加盟资料和报名详情。

收款分账：脱敏收款账户、渠道绑定入口、按店分账周期/比例/有效期版本、结算及接收方明细。未配置支付渠道时绑定返回503，规则发布检查账户已绑定、比例合计与有效期重叠；启用版本冻结。第九批数据库迁移已执行，累计118张表。

工资：薪资模板版本、员工薪资有效期关联、按店按月计算、销售/退款与消课来源明细、确认冻结。按整月模板计算；缺失或月内多模板时明确报错，未成功的重算保留原工资。示例费率仅开发演示，实际值由总部配置。第十批迁移和薪资示例已执行，完整125张表已在本地PostgreSQL建立。

第一阶段各管理模块已实现。浏览器验证账户/分账草稿保存、薪资新版本和月工资计算，示例上海一店实发4299.75元。页面使用内存Mock；真实数据库读写、持久任务和真实渠道接入属于后续Go阶段。

数据库表名已逐项对照设计，125张全部对应，无缺失；重复执行迁移和开发种子正常。累计38项业务检查、Mock及管理端类型检查通过。
