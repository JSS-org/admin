# 审批提交规范

业务页面统一使用 `create.vue`，通过 `businessType`、`sourceType`、`record` 带入上下文。审批中心也使用同一组件，不另建提交表单。

| 区域     | 规范                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 基本信息 | 审批类型、申请门店、已发布的同类型模板、申请事项（最多255字）                            |
| 业务信息 | 关联会员/卡模板、订单、合同、包月协议或课程；从业务入口带入的关联记录不可更换            |
| 申请说明 | 原因必填，去除首尾空格，最多2000字；改价填写非负金额，最多2位小数                        |
| 附件材料 | PDF / JPG / PNG，最多10个，单个不超过20 MB；签约必须有附件；可预览和移除                 |
| 提交行为 | 上传及提交期间禁用表单；失败保留内容；同一次提交复用幂等键；成功后提示到审批管理查看进度 |

入口：会员资料、会员卡模板、自主办卡记录提交开卡审批；合同记录、连续包月记录提交签约审批；课程产品提交改价审批。审批中心提供通用入口，其他审批需先发布模板。

`POST /admin/v1/approvals` 要求 `approvals:create`。申请人由登录账号关联员工确定，门店、业务数据、附件访问和模板有效性由服务端校验；业务快照、附件元信息和审批任务在提交时固定。不同入口对同一业务的待审批申请会去重。

`GET /admin/v1/approval-options` 只向可提交审批的账号提供已发布模板的必要信息，不开放模板管理权限。

审批详情统一显示申请内容、附件、审批流程及当前审批人的处理表单。审批意见选填，最多2000字；通过与拒绝均允许留空。提交结果后保留抽屉并刷新状态；无需再次打开意见抽屉。通过审批仅推进审批状态，业务履约仍由对应业务流程处理。

当前使用内存 Mock，文件和申请在 Mock 重启后重置。数据库结构由迁移 `014`、`015` 同步描述，迁移不由前端执行。

## 带附件的示例

每个示例门店包含开卡、签约、改价各一条审批，共六条。开卡附申请单，签约附已有合同和审核说明，改价附课程优惠方案。附件统一用表格展示文件名、类型、大小和操作，预览复用 `openGymFile()` 与现有文件预览标签页。文件名及内容明确标注模拟用途，不代表真实合同或业务申请。

列表操作、附件上传/预览/移除沿用带提示的图标操作；查询、刷新和提交等文字按钮不添加前置图标。
