# 上线前整理（2026-09-14）

本轮覆盖 `apps/web-antd` 健身门店后台的公共列表、登录入口、工作台、会员详情和代预约流程。

## 体验调整

- 工作台按会员服务、课程与经营组织入口，继续按现有菜单权限展示。
- 登录页使用门店业务文案，移除模板外观工具栏。仅本地开发且启用 Mock 时显示示例账号及自动填充。
- 统一页面标题、列表间距、状态颜色和空状态，会员持卡详情显示中文状态与本地时间。
- 筛选通过查询按钮或回车提交；失焦不会刷新。过滤空条件、修剪关键词两端空格，校验时间范围先后关系。
- 列表提供刷新、失败重试和清空筛选入口；请求失败不展示旧结果，记录减少导致页码越界时返回有效页。
- 代预约依次选择课程、会员、权益；加载期间禁用相关选择，丢弃过期请求，课程按开课时间排序并展示剩余名额。
- 权益选择检查门店、课程、有效期和已知剩余次数；唯一适用权益自动选中。最终名额、次卡预约占用与权限仍由服务端校验。
- 提交预约和取消预约防止连续点击；取消前明确展示会员和课程供确认。

- `apps/web-antd` 类型检查、生产构建，以及改动文件的 Oxfmt、ESLint、Stylelint、Oxlint 检查通过。

```sh

pnpm --filter @vben/web-antd typecheck
```

## 正式部署仍需完成

生产接口已从公共演示服务改为同源 `/api`。部署网关需将 `/api` 路径转发至实现现有接口契约的正式业务后端。当前仓库业务后端为内存 Mock，数据库迁移尚未与前端业务请求连通，不能将本轮前端构建通过视为整套系统已具备生产运行条件。

真实后端接入后仍需验证员工登录、门店权限隔离、会员资料持久化、预约名额并发及取消后的权益释放。本轮没有部署生产环境。
