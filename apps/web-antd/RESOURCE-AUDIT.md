# 后台页面外部资源检查

检查范围：`apps/web-antd` 当前启用的认证、gym 路由及其共享布局（2026-09-16）。

已处理：

- 29 种表格 actions、业务页面、上传按钮和侧栏折叠按钮改用随应用打包的 Lucide SVG 组件。
- 菜单和标签页图标的 SVG 数据按需打包并同步注册，保留可序列化的名称；新增路由图标需同步更新 `src/icons/route-icons.json`，覆盖测试会检查遗漏。
- 删除入口 HTML 中模板遗留的百度统计脚本。
- 将应用默认头像覆盖为本地 SVG，避免使用共享配置中的 unpkg 默认头像。该覆盖也应用于已保存的偏好设置。

保留的联网行为：

- `/api` 业务接口，以及业务数据提供的图片、视频、文件预览和下载地址。
- 门店地址的高德地图链接，仅在用户点击后打开。

代码中仍存在但当前后台未启用的外部资源能力：

- 共享图标选择器会从 Iconify 查询图标集合；通用 Iconify 组件对未注册的图标名称仍会联网加载。当前 gym 页面未使用图标选择器。
- 共享时区按钮、全局搜索快捷键图标使用在线图标；当前后台关闭了这些入口。
- 钉钉登录组件会加载阿里 CDN 脚本，当前认证页面未接入此组件。
- 通用 PWA 配置含 unpkg 图标，但本应用生产配置关闭 PWA；CDN importmap 也未启用。
- 模板演示页仍保留远程图标和外部链接；当前路由只加载 `modules/gym.ts`，这些演示页未接入。

启用上述功能时需要重新检查资源来源。当前生产 CSS 无外部字体或图片 URL。

验证结果：类型检查、ESLint、生产构建和菜单图标覆盖测试通过。Playwright 使用全新浏览器会话拦截外部 HTTP(S) 请求，检查登录页及首页、门店、员工、会员、会员卡、合同、设备、设置、展示配置页面；未发现第三方资源请求或页面异常。实际表格中 99 个操作按钮均有 SVG，单独挂载的全部 29 种 actions 也均正常渲染。
